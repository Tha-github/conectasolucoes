Acesso ao painel

Configuração feita uma vez pelo responsável técnico: cole a chave do GitHub (token fine-grained só deste repositório, com Contents: Read and write) e defina a senha do painel. A chave é gravada criptografada com a senha; ela nunca fica legível no site.

Publicar no site grava as alterações no repositório do GitHub; o site é atualizado para todos os visitantes em 1 a 3 minutos, depois da validação automática. Salvar rascunho guarda só neste navegador. Como funciona

Publicar, salvar e exportar

  1. Publicar no site

    Grava o conteúdo e as imagens novas no GitHub, num único registro. O GitHub valida tudo automaticamente e atualiza o site em 1 a 3 minutos. O painel avisa quando as mudanças já estiverem no ar. Se a validação recusar algo, o site continua como estava.

  2. Salvar rascunho

    Guarda as alterações apenas neste navegador, neste computador, sem publicar. Útil para continuar depois.

  3. Exportar e importar JSON

    Cópia de segurança do conteúdo validado, para guardar ou enviar ao responsável técnico.
