Salvar, exportar e publicar

  1. Salvar rascunho

    Guarda as alterações apenas neste navegador, neste computador. Ninguém mais vê. Limpar os dados do navegador apaga o rascunho.

  2. Exportar JSON

    Baixa um arquivo com todo o conteúdo validado. Se você trocou imagens, baixe também os arquivos de imagem indicados. Envie tudo ao responsável técnico.

  3. Publicar

    Quem tem acesso ao repositório no GitHub envia o content.json (e as imagens) numa branch conteudo/… e abre um Pull Request. O GitHub valida tudo automaticamente; depois do merge, o site é publicado. Sem esse acesso, envie os arquivos ao responsável técnico. Só então os visitantes veem as mudanças.
